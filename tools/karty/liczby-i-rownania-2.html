Zadania otwarte

  1. $a = 3$, $b = 0$; $x \in (-\infty, 0) \cup (1, 3)$. Z $W(1) = 0$ i $W(3) = 0$ mamy $a + b = 3$ oraz $3a + b = 9$. Stąd $W(x) = x^3 - 4x^2 + 3x = x(x - 1)(x - 3)$; wykres wielomianu zaczyna się „od dołu” i przecina oś w punktach $0$, $1$, $3$, więc $W(x) < 0$ dla $x < 0$ oraz dla $1 < x < 3$.
  2. $x = 3$ lub $x = -\frac{1}{3}$. Dziedzina: $x \neq 1$ i $x \neq -1$. Mnożymy przez $4(x - 1)(x + 1)$: $4(x + 1) + 4(x - 1) = 3(x^2 - 1)$, czyli $3x^2 - 8x - 3 = 0$, $\Delta = 100$, $x = \frac{8 \pm 10}{6}$.
  3. Zeszyt kosztuje $3$ zł, długopis kosztuje $2$ zł. Układ: $3z + 2d = 13$ oraz $2z + 5d = 16$. Mnożymy pierwsze równanie przez $5$, a drugie przez $2$ i odejmujemy: $11z = 33$, więc $z = 3$ i $d = 2$.
  4. Dowód: $a^2 + b^2 + 2 - 2a - 2b = (a^2 - 2a + 1) + (b^2 - 2b + 1) = (a - 1)^2 + (b - 1)^2 \geq 0$, bo suma kwadratów liczb rzeczywistych jest nieujemna.
  5. $x \in (-\infty, -1] \cup [4, +\infty)$. Nierówność jest równoważna alternatywie $2x - 3 \leq -5$ lub $2x - 3 \geq 5$, czyli $x \leq -1$ lub $x \geq 4$.
