Zadania otwarte

  1. $D_f = \mathbb{R} \setminus \{-2, 2\}$, miejsce zerowe: $x = 3$. Mianownik $x^2 - 4$ jest równy $0$ dla $x = \pm 2$. Licznik: $x^2 - x - 6 = (x - 3)(x + 2)$ ma pierwiastki $3$ i $-2$, ale $-2$ nie należy do dziedziny.
  2. $f(x) = \dfrac{-7}{x + 2} + 3$; asymptoty: $x = -2$ oraz $y = 3$. $\dfrac{3x - 1}{x + 2} = \dfrac{3(x + 2) - 7}{x + 2} = 3 - \dfrac{7}{x + 2}$.
  3. $x = 0$ lub $x = 1$. Podstawienie $t = 3^x > 0$ daje $t^2 - 4t + 3 = 0$, czyli $t = 1$ lub $t = 3$. Stąd $3^x = 1$ albo $3^x = 3$.
  4. $x = 3$. Dziedzina: $x > 1$. Równanie ma postać $\log_{2}\big((x + 1)(x - 1)\big) = 3$, więc $x^2 - 1 = 8$, $x = 3$ lub $x = -3$; liczba $-3$ nie należy do dziedziny.
  5. $k = -12$; punkt $B$ należy do wykresu; $x \in (-4, 0)$. Z $4 = \frac{k}{-3}$ mamy $k = -12$. Dla $B$: $f(6) = \frac{-12}{6} = -2$. Dla $x > 0$ funkcja jest ujemna, więc nierówność $-\frac{12}{x} > 3$ nie ma tam rozwiązań; dla $x < 0$ mnożenie przez $x$ zmienia zwrot: $-12 < 3x$, czyli $x > -4$.
