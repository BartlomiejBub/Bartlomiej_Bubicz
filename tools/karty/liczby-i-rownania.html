Zadanie 16. (0–3)

Zadania otwarte

  1. $x \in \left(-\infty, -\frac{1}{2}\right] \cup [3, +\infty)$. Pierwiastki trójmianu: $\Delta = 49$, $x_1 = -\frac{1}{2}$, $x_2 = 3$; ramiona paraboli są skierowane w górę.
  2. $x = -3$, $x = -2$, $x = 2$. Grupowanie: $x^2(x + 3) - 4(x + 3) = (x + 3)(x^2 - 4) = (x + 3)(x - 2)(x + 2)$.
  3. Dowód: $n^2 + (n + 1)^2 + 1 = 2n^2 + 2n + 2 = 2(n^2 + n + 1)$. Liczba $n^2 + n + 1$ jest całkowita, więc cała liczba jest podzielna przez $2$.
  4. Klasa A: $32$ uczniów, klasa B: $26$ uczniów. Układ równań: $a + b = 58$ oraz $0{,}75a + 0{,}5b = 37$.
  5. $5\,408$ zł. $5000 \cdot 1{,}04^2 = 5000 \cdot 1{,}0816 = 5408$.
