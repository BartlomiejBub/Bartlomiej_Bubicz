Zadania otwarte

  1. $f(x) = 2(x - 2)^2 - 9$. Z wierzchołka: $f(x) = a(x - 2)^2 - 9$; punkt $(0, -1)$ daje $4a - 9 = -1$, więc $a = 2$.
  2. Największa wartość: $6$ (dla $x = -1$), najmniejsza: $-3$ (dla $x = 2$). Wierzchołek paraboli $p = 2$ leży w przedziale; $f(-1) = 6$, $f(2) = -3$, $f(3) = -2$.
  3. $r = 3$. $S_{10} = \frac{2 \cdot 5 + 9r}{2} \cdot 10 = 50 + 45r = 185$.
  4. $x = 4$ (ciąg $3, 6, 12$). Warunek: $6^2 = (x - 1)(x + 8)$, czyli $x^2 + 7x - 44 = 0$, skąd $x = 4$ lub $x = -11$; dla $x = -11$ wyrazy nie są dodatnie.
  5. $15$ m × $30$ m, pole $450\ \text{m}^2$. Boki prostopadłe do muru mają długość $x$, więc $P(x) = x(60 - 2x) = -2x^2 + 60x$; największa wartość dla $x = 15$.
